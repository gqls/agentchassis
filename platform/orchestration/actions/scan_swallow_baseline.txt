# scan_swallow_baseline.txt — bugs_open/410
#
# Per-file counts of UNMARKED cursor-loop scan swallows: a `rows.Scan` inside a
# `for rows.Next()` loop whose error branch `continue`s, so the reader returns
# fewer rows than the cursor yielded and the caller cannot tell.
#
# READ BY TWO LAYERS, ONE PATTERN (the work_item_type_minting_ratchet_test.go
# rule — change them together):
#   - platform/orchestration/actions/scan_swallow_ratchet_test.go  (BLOCKING,
#     covers platform/orchestration/actions/** only)
#   - scripts/pattern-check.py check_scan_swallow                  (ADVISORY,
#     tree-wide, fires only on files a commit touches)
#
# ENTRIES ONLY EVER GO DOWN. A count that rises, or a file that appears, fails
# the ratchet: fix it with datahelpers.ScanShortfall (loadStoredSections in
# rerender_page_sections_action.go is the worked example) or mark the site
# `// scan-loss:accepted: <reason>` inside the error branch. A count that FALLS
# also fails, with an instruction to lower the entry here — so the baseline
# cannot silently drift and a net-zero swap cannot hide.
#
# Generated 2026-08-26. 207 sites in 127 files; 166 of them in the blocking
# scope. Paths are repo-root-relative. Regenerate by re-running the census, do
# not hand-edit except to lower a count.
#
# NOT a list of bugs. Most of these are harmless — a swallow only destroys
# something when the caller's result feeds a wholesale replace or is reported as
# complete. The list exists to stop the population GROWING, and to make a
# fix-on-touch cheap, not to imply 207 defects.
#
# PARITY RE-CHECK (architecture seat, round c8385154 — verified once at ship
# time, NOT mechanically enforced; if the two classifiers drift, "one baseline,
# two readers" silently becomes two baselines). Re-run whenever either
# classifier is edited, and opportunistically when touching this file:
#
#   python3 - <<'EOF'
#   import importlib.util, os
#   spec = importlib.util.spec_from_file_location("pc", "scripts/pattern-check.py")
#   pc = importlib.util.module_from_spec(spec); spec.loader.exec_module(pc)
#   base = pc._scan_swallow_baseline(None); actual = {}
#   for d in ["platform","internal","pkg","cmd"]:
#       for dp,_,fns in os.walk(d):
#           for fn in fns:
#               if fn.endswith(".go") and not fn.endswith("_test.go"):
#                   p=os.path.join(dp,fn)
#                   c=pc._count_scan_swallows(open(p,encoding="utf-8",errors="replace").read())
#                   if c: actual[p]=c
