# Agent Communication Flow - Stateless-First Go Implementation

## Architecture Philosophy: Stateless Agents with Database-Backed Orchestrations

**Core Principle**: Agents are stateless executors. State lives in the database. Any replica can process any message for its agent type.

```go
// The REAL identity and state holder
Orchestration (in DB) + Step + Request = "Agent Instance"

// The executor (stateless, ephemeral)
Agent Container (any replica) = Processes messages, updates DB
```

## Complete Message Flow: Core Manager → Agent-Chassis → Test-One-v1

### 1. Stateless Agent Architecture (Go Structures)

// Agent represents a stateless executor
type Agent struct {
    // Type configuration (same for all replicas)
    AgentType    string `json:"agent_type"`     // "agent-chassis", "website-builder"
    AgentVersion string `json:"agent_version"`  // "v1.2.3"
    WorkflowType string `json:"workflow_type"`  // Type of workflows this agent handles
    
    // Instance identification (unique per pod, for debugging only)
    PodName     string `json:"pod_name"`      // This IS the AgentID
    Namespace   string `json:"namespace"`     // Kubernetes namespace
    NodeName    string `json:"node_name"`     // Which K8s node it's running on
    
    // Shared resources (all replicas use same topics)
    RequestsTopic  string `json:"requests_topic"`   // e.g., "system.agent-chassis.requests"
    ResponsesTopic string `json:"responses_topic"`  // e.g., "system.agent-chassis.responses"
    
    // NO internal orchestration state! It's all in DB
    db    *DatabaseClient
    kafka *KafkaClient
}

// OrchestrationState is the REAL stateful entity (stored in DB)
type OrchestrationState struct {
    // Identity
    OrchestrationID   string `json:"orchestration_id"`    // UUID
    OrchestrationName string `json:"orchestration_name"`  // Human-readable
    AgentType        string `json:"agent_type"`          // Which agent type handles this
    
    // Hierarchy
    ParentOrchestrationID   string `json:"parent_orchestration_id"`
    ParentOrchestrationName string `json:"parent_orchestration_name"`
    ParentRequestID        string `json:"parent_request_id"`
    CorrelationID          string `json:"correlation_id"`
    CorrelationName        string `json:"correlation_name"`
    
    // State
    CurrentStep      int                `json:"current_step"`
    TotalSteps      int                `json:"total_steps"`
    Status          string             `json:"status"` // pending|processing|complete|failed
    AwaitedRequests map[string]bool    `json:"awaited_requests"` // RequestID -> awaiting
    
    // Optimistic locking
    Version int `json:"version"` // Incremented on each update
    
    // Audit trail (for debugging)
    ProcessingHistory []ProcessingRecord `json:"processing_history"`
    CreatedAt        time.Time          `json:"created_at"`
    UpdatedAt        time.Time          `json:"updated_at"`
}

type ProcessingRecord struct {
    PodName   string    `json:"pod_name"`   // Which pod processed this
    StepID    string    `json:"step_id"`
    StepName  string    `json:"step_name"`
    Action    string    `json:"action"`     // "sent_request", "received_response", etc.
    Timestamp time.Time `json:"timestamp"`
    Details   string    `json:"details"`    // Any relevant debug info
}

// GetAgentIdentity for stateless agents - AgentID = PodName
func GetAgentIdentity(agentType string) *AgentIdentity {
    podName := os.Getenv("HOSTNAME") // In K8s, hostname = pod name
    if podName == "" {
        podName = fmt.Sprintf("%s-local-%d", agentType, os.Getpid())
    }
    
    return &AgentIdentity{
        AgentType:    agentType,
        AgentID:      podName,  // AgentID = PodName for stateless design
        PodName:      podName,
        AgentVersion: os.Getenv("AGENT_VERSION"),
    }
}

// NewStatelessAgent creates an agent that processes messages without internal state
func NewStatelessAgent(agentType string, db *DatabaseClient, kafka *KafkaClient) *Agent {
    return &Agent{
        AgentType:    agentType,
        AgentVersion: os.Getenv("AGENT_VERSION"),
        WorkflowType: os.Getenv("WORKFLOW_TYPE"),
        PodName:      os.Getenv("HOSTNAME"),
        Namespace:    os.Getenv("POD_NAMESPACE"),
        NodeName:     os.Getenv("NODE_NAME"),
        
        // Shared topics for all replicas of this agent type
        RequestsTopic:  fmt.Sprintf("system.%s.requests", agentType),
        ResponsesTopic: fmt.Sprintf("system.%s.responses", agentType),
        
        db:    db,
        kafka: kafka,
    }
}

// ProcessMessage handles any message for this agent type
func (a *Agent) ProcessMessage(ctx context.Context) error {
    // Any replica can process any message
    msg, err := a.kafka.ConsumeNext(a.RequestsTopic)
    if err != nil {
        return err
    }
    
    // Load orchestration state from DB (not from memory!)
    state, err := a.loadOrUpdateOrchestration(msg)
    if err != nil {
        return err
    }
    
    // Process based on current state
    return a.executeStep(ctx, state, msg)
}
```

### 3. Database-Backed State Management (Go)

```go
// loadOrUpdateOrchestration loads state from DB or creates new orchestration
func (a *Agent) loadOrUpdateOrchestration(msg RequestMessage) (*OrchestrationState, error) {
    // Try to load existing orchestration for responses
    if msg.Headers.MessageType == "response" {
        orchID := msg.Headers.InResponseToOrchID
        return a.db.LoadOrchestrationWithLock(orchID)
    }
    
    // For new requests, create orchestration
    orch := &OrchestrationState{
        OrchestrationID:         uuid.New().String(),
        OrchestrationName:       GenerateReadableName(a.AgentType, msg.Headers.Action),
        AgentType:              a.AgentType,
        ParentOrchestrationID:   msg.Headers.OrchestrationID,
        ParentOrchestrationName: msg.Headers.OrchestrationName,
        ParentRequestID:        msg.Headers.RequestID,
        CorrelationID:          msg.Headers.CorrelationID,
        CorrelationName:        msg.Headers.CorrelationName,
        CurrentStep:            1,
        Status:                 "processing",
        AwaitedRequests:        make(map[string]bool),
        Version:                1,
        ProcessingHistory:      []ProcessingRecord{},
        CreatedAt:             time.Now(),
        UpdatedAt:             time.Now(),
    }
    
    // Add processing record
    orch.ProcessingHistory = append(orch.ProcessingHistory, ProcessingRecord{
        PodName:   a.PodName,
        StepID:    msg.Headers.StepID,
        StepName:  msg.Headers.StepName,
        Action:    "orchestration_created",
        Timestamp: time.Now(),
        Details:   fmt.Sprintf("Created by %s for action %s", a.PodName, msg.Headers.Action),
    })
    
    return orch, a.db.SaveOrchestration(orch)
}

// executeStepWithOptimisticLocking ensures only one replica processes a step
func (a *Agent) executeStepWithOptimisticLocking(
    ctx context.Context,
    orchID string,
    stepFunc func(*OrchestrationState) error,
) error {
    maxRetries := 3
    for i := 0; i < maxRetries; i++ {
        // Load current state with version
        state, err := a.db.LoadOrchestrationWithVersion(orchID)
        if err != nil {
            return err
        }
        
        currentVersion := state.Version
        
        // Execute the step
        if err := stepFunc(state); err != nil {
            return err
        }
        
        // Update processing history
        state.ProcessingHistory = append(state.ProcessingHistory, ProcessingRecord{
            PodName:   a.PodName,
            Action:    "step_executed",
            Timestamp: time.Now(),
            Details:   fmt.Sprintf("Processed by %s", a.PodName),
        })
        
        // Try to save with version check
        state.Version = currentVersion + 1
        state.UpdatedAt = time.Now()
        
        err = a.db.SaveOrchestrationIfVersion(state, currentVersion)
        if err == nil {
            // Success!
            return nil
        }
        
        if err == ErrVersionMismatch {
            // Another replica processed it, retry
            log.Printf("Version mismatch for %s, retrying... (attempt %d)", orchID, i+1)
            time.Sleep(time.Millisecond * 100 * time.Duration(i+1))
            continue
        }
        
        return err
    }
    
    return fmt.Errorf("max retries exceeded for orchestration %s", orchID)
}

```go
// HandleResponse can be processed by ANY agent-chassis replica
func (ac *Agent) HandleResponse(resp ResponseMessage) error {
    myIdentity := GetAgentIdentity("agent-chassis")
    orchID := resp.Headers.InResponseToOrchID
    requestID := resp.Headers.InResponseToRequestID
    
    log.Printf("Agent-Chassis replica [%s] handling response for request %s",
        myIdentity.PodName, requestID)
    
    // Use optimistic locking to handle response
    return ac.executeStepWithOptimisticLocking(
        context.Background(),
        orchID,
        func(state *OrchestrationState) error {
            // Check if we're waiting for this
            if !state.AwaitedRequests[requestID] {
                return fmt.Errorf("not awaiting request %s", requestID)
            }
            
            // Add processing record
            state.ProcessingHistory = append(state.ProcessingHistory, ProcessingRecord{
                PodName:   myIdentity.PodName,
                StepID:    resp.Headers.InResponseToStepID,
                StepName:  resp.Headers.InResponseToStepName,
                Action:    fmt.Sprintf("received_%s_response", resp.Headers.Status),
                Timestamp: time.Now(),
                Details:   fmt.Sprintf("Handled by %s", myIdentity.PodName),
            })
            
            // Handle based on status
            switch resp.Headers.Status {
            case "awaiting", "processing":
                // Progress update - don't propagate, just log
                log.Printf("Progress for %s: %s", requestID, resp.Headers.Status)
                return nil
                
            case "complete":
                // Remove from awaited
                delete(state.AwaitedRequests, requestID)
                
                // If all requests complete, mark orchestration complete
                if len(state.AwaitedRequests) == 0 {
                    state.Status = "complete"
                }
                
                // Send response to parent
                parentResponse := ResponseMessage{
                    Headers: ResponseHeaders{
                        Sender:                      *myIdentity,
                        InResponseToRequestID:       state.ParentRequestID,
                        InResponseToOrchID:         state.ParentOrchestrationID,
                        InResponseToOrchName:       state.ParentOrchestrationName,
                        MyOrchestrationID:          state.OrchestrationID,
                        MyOrchestrationName:        state.OrchestrationName,
                        Status:                     "complete",
                        IsComplete:                 true,
                        CorrelationID:              state.CorrelationID,
                        CorrelationName:            state.CorrelationName,
                        FuelUsed:                   resp.Headers.FuelUsed + 100,
                        RemainingFuelBudget:        resp.Headers.RemainingFuelBudget - 100,
                    },
                    Body: resp.Body,
                }
                
                // Determine parent's response topic based on agent type
                parentTopic := fmt.Sprintf("system.%s.responses", 
                    extractAgentType(state.ParentOrchestrationName))
                
                return ac.kafka.PublishWithKey(
                    parentTopic,
                    state.ParentOrchestrationID,  // Partition by parent orchestration
                    parentResponse,
                )
                
            case "error_recoverable":
                // Implement retry logic
                if state.RetryCount < 3 {
                    state.RetryCount++
                    return ac.retryRequest(state, requestID)
                }
                // Max retries exceeded
                fallthrough
                
            case "error_unrecoverable":
                delete(state.AwaitedRequests, requestID)
                state.Status = "failed"
                return ac.sendErrorToParent(state, resp)
            }
            
            return nil
        },
    )
}

func (ac *AgentChassis) HandleTestAgentResponse(resp ResponseMessage) error {
    requestID := resp.Headers.InResponseToRequestID
    
    // Check if we're waiting for this
    awaited, exists := ac.awaitedRequests[requestID]
    if !exists {
        log.Printf("ERROR: Not waiting for request %s", requestID)
        log.Printf("Awaited requests: %v", ac.awaitedRequests)
        return fmt.Errorf("unexpected response for request %s", requestID)
    }
    
    // Handle based on status
    switch resp.Headers.Status {
    case "awaiting", "processing":
        // Progress update - don't propagate up
        log.Printf("Progress update for %s: %s", requestID, resp.Headers.Status)
        return nil
        
    case "complete":
        // Remove from awaited
        delete(ac.awaitedRequests, requestID)
        
        // Send response to Core Manager
        finalResponse := ResponseMessage{
            Headers: ResponseHeaders{
                // Original request context
                InResponseToRequestID:    awaited.ParentRequestID,
                InResponseToStepID:      awaited.ParentStepID,
                InResponseToParentOrchID: awaited.ParentOrchestrationID,
                RetryCount:              awaited.RetryVersion,
                
                // My context
                MyOrchestrationID: ac.orchestrationID,
                
                // Status
                Status:     "complete",
                IsComplete: true,
                
                // Pass through correlation
                CorrelationID: resp.Headers.CorrelationID,
                
                // Resources
                FuelUsed:            resp.Headers.FuelUsed + 100,
                RemainingFuelBudget: resp.Headers.RemainingFuelBudget - 100,
            },
            Body: resp.Body, // Pass through the result
        }
        
        return ac.kafka.Publish("system.agent.core.responses", finalResponse)
        
    case "error_recoverable":
        // Retry with same request ID, increment retry version
        if awaited.RetryVersion < 3 {
            return ac.retryRequest(awaited)
        }
        // Max retries exceeded, treat as unrecoverable
        fallthrough
        
    case "error_unrecoverable":
        // Remove from awaited and propagate error
        delete(ac.awaitedRequests, requestID)
        return ac.sendErrorToParent(awaited, resp)
    }
    
    return nil
}
```

### 7. Deduplication Handler (Go)

```go
type MessageDeduplicator struct {
    processedMessages map[string]*ProcessedMessage
    mu                sync.RWMutex
}

type ProcessedMessage struct {
    MessageID    string
    RequestID    string
    RetryVersion int
    Status       string
    ProcessedAt  time.Time
}

func (md *MessageDeduplicator) ShouldProcess(resp ResponseMessage) bool {
    md.mu.Lock()
    defer md.mu.Unlock()
    
    // Key for deduplication
    key := fmt.Sprintf("%s:%d:%s", 
        resp.Headers.InResponseToRequestID,
        resp.Headers.RetryCount,
        resp.Headers.Status)
    
    if existing, exists := md.processedMessages[key]; exists {
        log.Printf("Duplicate response ignored: %s (already processed at %v)", 
            key, existing.ProcessedAt)
        return false
    }
    
    // For terminal states, check if we've already processed ANY terminal state for this request
    if resp.Headers.Status == "complete" || resp.Headers.Status == "error_unrecoverable" {
        baseKey := fmt.Sprintf("%s:*:terminal", resp.Headers.InResponseToRequestID)
        if _, exists := md.processedMessages[baseKey]; exists {
            log.Printf("Terminal state already processed for request %s", 
                resp.Headers.InResponseToRequestID)
            return false
        }
        // Mark as terminal
        md.processedMessages[baseKey] = &ProcessedMessage{
            RequestID:   resp.Headers.InResponseToRequestID,
            Status:      "terminal",
            ProcessedAt: time.Now(),
        }
    }
    
    // Mark as processed
    md.processedMessages[key] = &ProcessedMessage{
        MessageID:    resp.Headers.InResponseToMessageID,
        RequestID:    resp.Headers.InResponseToRequestID,
        RetryVersion: resp.Headers.RetryCount,
        Status:       resp.Headers.Status,
        ProcessedAt:  time.Now(),
    }
    
    return true
}

func (k *KafkaClient) PublishWithKey(topic string, key string, msg interface{}) error {
    // Use orchestration ID as partition key
    // This ensures all messages for one orchestration are ordered
    return k.producer.Send(&sarama.ProducerMessage{
        Topic: topic,
        Key:   sarama.StringEncoder(key),  // Orchestration ID
        Value: msg,
    })

// Consumer group ensures each message processed once across replicas
func (k *KafkaClient) CreateConsumerGroup(groupID string, topics []string) error {
    config := sarama.NewConfig()
    config.Consumer.Group.Rebalance.Strategy = sarama.BalanceStrategyRoundRobin
    config.Consumer.Offsets.Initial = sarama.OffsetNewest

    // e.g., "agent-chassis-consumers", "test-one-v1-consumers"
    consumerGroup, err := sarama.NewConsumerGroup(k.brokers, groupID, config)
    if err != nil {
        return err
    }
    
    // All replicas join the same consumer group
    // Kafka automatically distributes partitions among replicas
    return nil
}

## Key Implementation Notes

1. **Request IDs are unique per step task** - not per message
2. **Retry uses same request_id with incremented retry_version**
3. **Track awaited_requests by request_id**, not step_id
4. **Each agent creates its own orchestration_id**
5. **Progress updates (awaiting/processing) don't propagate up**
6. **Terminal states (complete/error) process once**
7. **Full context preserved in response headers for debugging**

```go
// Main execution loop for stateless agent
func (a *Agent) Run(ctx context.Context) error {
    // Join consumer group (Kafka handles partition assignment)
    consumerGroup := fmt.Sprintf("%s-consumers", a.AgentType)
    consumer, err := a.kafka.JoinConsumerGroup(consumerGroup, []string{a.RequestsTopic})
    if err != nil {
        return err
    }
    
    log.Printf("[%s/%s] Started, consuming from %s", 
        a.AgentType, a.PodName, a.RequestsTopic)
    
    for {
        select {
        case <-ctx.Done():
            return ctx.Err()
            
        case msg := <-consumer.Messages():
            // Any replica can process any message
            if err := a.processMessage(msg); err != nil {
                log.Printf("[%s/%s] Error processing message: %v", 
                    a.AgentType, a.PodName, err)
                // Message will be retried by Kafka
                continue
            }
            
            // Commit offset only after successful processing
            consumer.MarkOffset(msg, "")
        }
    }
}

func (a *Agent) processMessage(kafkaMsg *sarama.ConsumerMessage) error {
    var msg Message
    if err := json.Unmarshal(kafkaMsg.Value, &msg); err != nil {
        return err
    }
    
    // Deduplication check
    if a.isDuplicate(msg) {
        log.Printf("[%s/%s] Skipping duplicate message %s", 
            a.AgentType, a.PodName, msg.Headers.MessageID)
        return nil
    }
    
    switch msg.Headers.MessageType {
    case "request":
        return a.HandleRequest(msg.(RequestMessage))
    case "response":
        return a.HandleResponse(msg.(ResponseMessage))
    default:
        return fmt.Errorf("unknown message type: %s", msg.Headers.MessageType)
    }
}

func (a *Agent) isDuplicate(msg Message) bool {
    // Create deduplication key
    var key string
    if msg.Headers.MessageType == "response" {
        resp := msg.(ResponseMessage)
        key = fmt.Sprintf("%s:%d:%s",
            resp.Headers.InResponseToRequestID,
            resp.Headers.RetryCount,
            resp.Headers.Status)
    } else {
        req := msg.(RequestMessage)
        key = fmt.Sprintf("%s:%d",
            req.Headers.RequestID,
            req.Headers.RetryVersion)
    }
    
    // Check if already processed
    exists, err := a.db.MessageExists(key)
    if err != nil {
        log.Printf("Dedup check error: %v", err)
        return false  // Process anyway on error
    }
    
    if exists {
        return true
    }
    
    // Mark as processed
    a.db.MarkMessageProcessed(key, msg.Headers.MessageID, a.PodName)
    return false
}
```

## Benefits of Stateless-First Design

### 1. **Resilience**
- Pod crashes don't lose orchestration state
- Any replica can pick up where another left off
- No single point of failure

### 2. **Scalability**
- Horizontal scaling with HPA
- Kafka consumer groups automatically rebalance
- Database handles concurrency with optimistic locking

### 3. **Simplicity**
- No complex state synchronization
- No leader election needed
- Pod name as Agent ID is sufficient

### 4. **Observability**
- Processing history shows which pods handled what
- Easy to trace issues to specific pods
- Clear audit trail in database

## Key Architectural Decisions

### 1. **State Location**
```
Database: Orchestration state, awaited requests, processing history
Kafka: Message queues, ordering guarantees
Agents: Stateless processors only
```

### 2. **Identity Model**
```
AgentID = PodName (changes on restart, but that's OK)
Orchestration = Persistent identity in database
```

### 3. **Concurrency Control**
```
Optimistic locking: Prevents duplicate processing
Kafka partitioning: Ensures message ordering per orchestration
Consumer groups: Automatic work distribution
```

### 4. **Topic Structure**
```
Per agent TYPE, not per instance:
- system.agent-chassis.requests (all replicas consume)
- system.agent-chassis.responses (all replicas consume)
```
