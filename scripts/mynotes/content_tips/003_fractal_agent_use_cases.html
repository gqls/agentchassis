00 — Architecture

Why hierarchy matters

Every agent is an orchestrator. It receives a task, reasons about how to decompose it, spawns specialist child agents, collects their results, synthesises an answer, and reports to its own parent. The tree grows and prunes itself.

The fractal pattern

A root agent decomposes a problem into sub-problems. Each child agent does the same for its piece. Children report back to parents, who synthesise and report upward. Every node stores its own state, reasoning, and results independently — creating a navigable tree of insight at every level of granularity.

Agents communicate through message passing, not direct calls. A parent doesn't need to know where its children run — only that they'll respond. This decoupling is what enables scaling across clusters, data centres, and regions without changing a line of agent logic.

01 — Economics & Markets

Simulating economies with reasoning agents

Traditional economic simulations use rule-based actors. These use agents that actually reason in natural language about their self-interest, producing emergent behaviour no designer scripted.

Million-Agent Market Economy

Each agent gets a persona — a business, a consumer, a regulator — with starting capital, preferences, and constraints. Businesses set prices, consumers shop around, suppliers negotiate with middlemen. Nobody scripts the outcomes. A million LLM-powered actors make self-interested decisions and the system watches what emerges.

Does price equilibrium form? Do monopolies emerge? Do agents discover arbitrage opportunities the designers didn't anticipate? Run the same scenario with different starting conditions and compare the distributions.

Output: Trading network visualisations, price movement timeseries, wealth distribution curves, emergent market structure maps — a dataset that economists would find genuinely novel.
emergent behaviour market dynamics agent-based economics
Job Market & Business Landscape Forecasting

Model a city-sized economy — 300,000 business-agents across every sector, each with an industry, headcount, revenue model, and technology adoption level. Introduce shocks: "AI coding tools got 10x better," "energy costs doubled," "remote work became the legal default."

Each business-agent reasons about whether to hire, fire, restructure, or pivot. They interact as customers and suppliers — when marketing agencies shrink, freelance copywriters feel it, which affects the coffee shops near their coworking spaces. Second and third order effects emerge from the agent interactions, not from equations.

Output: Month-by-month employment timelines, sector growth/contraction maps, job title evolution predictions, workforce retraining need forecasts. Run the same shock 100 times to get probability distributions.
labour markets policy simulation scenario planning cascading effects
Supply Chain Stress Testing

Model a global supply chain as a tree. The top agent is a manufacturer. It spawns tier-1 supplier agents, each of which spawns tier-2 suppliers, down to raw materials. Each agent knows its lead times, inventory, alternative sources, and financial health.

Introduce a disruption — a factory floods, a shipping lane closes, a trade embargo hits. Watch the effects propagate up the tree as each agent reasons about its response: find alternatives, burn inventory, warn the parent, or halt production. Run the same disruption 100 times with varied agent reasoning and get a probability distribution of supply chain resilience.

Output: Disruption propagation timelines, node-by-node decision audit trails, resilience scores per supply chain branch, identification of single points of failure.
supply chain risk modelling hierarchical propagation
Corporate M&A Due Diligence

A root agent receives "should Company A acquire Company B?" and spawns children for each due diligence workstream: financial, legal, technical, cultural, market position, regulatory risk. Each workstream spawns specialists — the financial agent creates sub-agents for revenue quality, cost synergies, debt structure, and hidden liabilities.

Each leaf agent investigates its focused question and stores a finding with confidence and risk ratings. Findings flow up through parents who synthesise workstream-level assessments. The root produces a recommendation with explicit trade-off reasoning.

Output: A complete due diligence tree — navigable from high-level recommendation down to individual findings. Run for 100 hypothetical acquisitions to build a training dataset for M&A decision-making.
due diligence financial analysis decision trees
02 — Environment & Ecology

Modelling ecological systems at continental scale

Each agent represents a unit of land, water, or atmosphere. They reason about local conditions, communicate with neighbours about cascading effects, and produce emergent ecosystem-level behaviour from individual interactions.

Data Centre Wildlife Impact Assessment

Each agent represents a square kilometre of land, holding its current ecology (woodland, grassland, wetland, urban), biodiversity indicators, water table depth, and proximity to infrastructure. Place a data centre and the surrounding agents begin reasoning about cascading effects — heat output altering microclimate, water extraction lowering the water table, construction disrupting migration corridors, light pollution affecting nocturnal species.

Agents communicate with neighbours: "My water table dropped 2 metres, what's happening to your marsh?" The reasoning goes beyond formulas — a riverside meadow agent considers which specific effects matter most for its ground-nesting bird population. Run it for 50 proposed data centre sites and produce comparative impact assessments.

Output: Ecological damage heatmaps propagating outward from each site over simulated years, biodiversity impact rankings, water table modelling, mitigation strategy comparisons.
ecology environmental impact spatial modelling infrastructure planning
Desert Regreening Simulation

Each agent is a hectare of desert or semi-arid land, holding soil composition, rainfall, elevation, wind patterns, and distance from existing vegetation. Simulate interventions — tree planting, water harvesting structures, managed grazing — and let agents reason about local effects and communicate cascading changes to neighbours.

"My trees are 3 metres tall and providing windbreak — what's your evaporation rate doing?" Agents capture non-obvious interactions: "my goat-herding neighbour's overgrazing is undoing my reforestation because their runoff erodes my terraces." Model the entire Sahel at 5 hectares per agent. Compare intervention strategies at continental scale.

Output: Time-lapse greening maps under different intervention strategies, feedback loop identification, cost-per-hectare efficiency rankings, tipping point predictions for self-sustaining vegetation.
climate reforestation feedback loops Sahel
Ecosystem Succession Modelling

A forest burns. The root agent represents the burned area and spawns agents for ecological succession stages: pioneer species, early succession, mid succession, climax community. These are sequential — each stage's output becomes the next stage's input.

The pioneer agent spawns children for specific species (fireweed, mosses, fungi), each reasoning about whether conditions suit them, competing with siblings for resources. When the pioneer stage completes, its aggregated result feeds into the early succession parent, which spawns its own species agents. Introduce disturbances at any point and watch how the current generation adapts.

Output: Complete succession pathways with every species' trajectory preserved, disturbance response analysis, comparative timelines under different management strategies.
ecology succession temporal hierarchy
03 — Society & Policy

Simulating human decision-making at population scale

Rule-based models capture mechanics. LLM agents capture the messiness of human reasoning — the single parent who can't afford to isolate, the swing voter reconsidering after a conversation with a neighbour.

Pandemic Response Simulation

Each agent is a person with a location, social connections, health profile, and behavioural tendencies — compliance level, information sources, trust in institutions. Release a pathogen and let agents decide how to respond. Do they mask, isolate, seek treatment, spread misinformation, panic-buy?

Agents reason about individual circumstances: "I'm a single parent with no sick pay, I can't afford to isolate even though I know I should." Policy interventions (lockdowns, vaccine rollouts, communication campaigns) affect different agents differently based on their reasoning. The epidemic curve emerges from a million individual decisions, not from an equation.

Output: Epidemic curves emerging from individual behaviour, policy intervention comparisons, compliance heat maps by demographic, identification of superspreader reasoning patterns.
epidemiology behavioural modelling policy testing
Legislation Impact Analysis

Start with a proposed law — "ban on single-use plastics." A top-level agent spawns industry-sector children: food packaging, retail, hospitality, medical, logistics. Each sector agent spawns children for sub-impacts: cost of alternatives, supply chain disruption, consumer behaviour change, small vs large business effects.

Children spawn further as needed — a supply chain agent might create sub-agents for specific replacement materials (paper, bioplastic, glass, aluminium) to research availability and pricing. Cross-branch communication catches interactions: "inflationary effects partially offset poverty reduction." Every node stores independently, creating a navigable impact assessment tree.

Output: Multi-level impact assessments for any proposed legislation, cross-sector dependency maps, unintended consequence identification, comparative analysis across 50+ policy proposals.
policy analysis cross-sector legislation
Election Simulation

One million voter-agents, each with a demographic profile, political leanings, media consumption habits, and social connections. Campaign events, debates, scandals, and economic data flow through the network. Each agent reasons about how news affects their vote intention and influences neighbours through simulated conversation.

Run 100 times with slightly different random seeds and produce probability distributions of outcomes. The hierarchical structure groups voters by constituency, region, and demographic — each level stores aggregated voting patterns that emerge from the individual reasoning below.

Output: Probability distributions of election outcomes, swing voter identification, message effectiveness analysis, social influence propagation maps.

Climate Migration Modelling

Root agent represents a continent, spawning country agents, then regional, city, and neighbourhood agents. Each level knows its climate projections, economic conditions, and social factors. As climate changes progress, leaf agents reason about liveability and "decide" whether their population stays or moves.

Effects cascade both ways — when a city agent reports significant inward migration, it pushes updated conditions back down to its children: housing pressure, job competition, infrastructure strain. Neighbourhood agents then reason about those second-order effects. The output is a century-long migration map with explanations at every level of the hierarchy.

Output: Multi-decade migration flow maps, tipping point identification per region, infrastructure strain predictions, policy intervention comparisons.

Food & Diet Futures

Each agent has a demographic profile: age, location, income, current diet, health conditions. Fed real trend data — plant-based adoption rates, ultra-processed food consumption, food price indices — they make food choices month by month, influenced by neighbours (social effects), prices, and health events ("my agent just developed type 2 diabetes").

At a million agents, model an entire city's adult population. Compare interventions: "subsidise fruit and veg by 20%" versus "ban advertising of ultra-processed food to under-16s." The hierarchical structure groups agents by neighbourhood, borough, and city — each level aggregates the dietary patterns emerging below.

Output: Predicted dietary shift maps over 10 years, health outcome forecasts, food desert analysis, intervention effectiveness rankings.

City Evolution Simulation

Each agent is a city block, knowing its current land use, property values, transport links, and neighbours. Introduce a change — a new train station, a factory closing, a flood — and let agents reason about how their block evolves over 20 simulated years.

"The new station increased my property values, pushing out small businesses in favour of chains, making the area less distinctive, which..." Agents negotiate shared resources with neighbours. The hierarchical grouping into streets, neighbourhoods, boroughs, and city gives planners insight at every administrative level.

04 — Science & Research

Distributed reasoning over knowledge

The hierarchical structure mirrors how knowledge itself is organised — fields decompose into sub-fields, which decompose into specific questions. Agents at every level synthesise the work below them.

Scientific Literature Mapping

Give the root agent a research question: "what are the current approaches to treating antibiotic resistance?" It spawns children for major approaches — phage therapy, new antibiotic development, combination therapies, prevention strategies. Each child researches its area and spawns further children for specific sub-topics.

The depth of investigation is adaptive — rich areas spawn more children, thin areas stay as leaves. Results flow up with each parent synthesising the landscape below. Scale to a million agents and map an entire scientific field into a queryable knowledge hierarchy.

Output: Navigable literature review trees, research gap identification, cross-disciplinary connection mapping, trend analysis across sub-fields.
literature review knowledge mapping adaptive depth
Collaborative Knowledge Graph Construction

Give each agent a single encyclopaedia article (there are over 6 million in English alone). Each agent extracts key claims and then messages neighbouring agents — articles that link to each other — to cross-reference and fact-check. "You say the population is 15 million, but my article says 21 million — which of us is outdated?"

Agents negotiate disagreements and produce a cleaned, cross-referenced knowledge graph. The hierarchical structure groups articles by topic, domain, and discipline, with parent agents identifying systemic inconsistencies.

Output: A million-node knowledge graph with annotated edges showing contradictions, a publishable dataset of factual inconsistencies across a major reference work.
knowledge graphs fact checking cross-referencing
Emergent Language Research

Start a million agents with no shared language. Each can message a small number of neighbours. Give them a coordination task — agree on labels for 100 objects — but with no starting vocabulary. They communicate by sending short strings and observing responses.

Over thousands of rounds, do they converge on a shared vocabulary? How many distinct languages form? Do dialects emerge at network boundaries? This is a genuine research question in computational linguistics, done with small neural agents in labs but never at this scale with LLM-powered reasoning.

Output: Language convergence timelines, dialect boundary maps, vocabulary evolution traces, comparison with real-world language family branching patterns.
linguistics emergent communication network effects
Historical Counterfactual Simulation

Pick a pivotal moment — June 1914. Spawn agents for each major power, and within each, spawn faction agents: military establishment, industrial lobby, diplomatic corps, head of state. Each faction reasons about its interests given the current situation and reports recommendations to the nation-parent, which synthesises a national response.

Then change one variable: the assassination doesn't happen. The same factions with the same interests reason about a different situation. Run 1,000 variations with different faction personalities and get a probability distribution: "war was X% likely even without the trigger." The stored state at every node lets historians examine each faction's reasoning at each moment.

Output: Counterfactual probability distributions, faction-level decision audit trails, causal pathway analysis, comparative historiographic datasets.
historiography counterfactual Monte Carlo decision analysis
Swarm Problem Solving

Pick an optimisation problem. Give each agent a slightly different starting approach. They try their method, share partial results with neighbours, and adapt. A hierarchical structure groups agents into "research teams" with team-lead agents that synthesise the most promising directions and redirect their children.

Essentially ant colony optimisation with reasoning instead of pheromone trails. Even if individual agents aren't strong mathematicians, a million agents exploring a million paths and communicating promising leads may converge on heuristics no individual would find. The evolutionary structure means winning strategies reproduce and losing ones are pruned.

Output: Solution quality over time, emergent search strategy visualisations, comparison of hierarchical vs flat swarm approaches, heuristic discovery traces.
optimisation swarm intelligence evolutionary search
Argument Decomposition & Analysis

Give the root agent a controversial claim: "universal basic income would reduce crime." It spawns children for each major line of reasoning — economic, psychological, sociological, empirical evidence, counterarguments. Each child decomposes further. Leaf agents research specific sub-arguments.

Agents in different branches communicate when they find cross-cutting dependencies: "if UBI causes inflation, the poverty reduction is partially offset." The stored result at each node is a self-contained argument with explicit dependencies on other nodes — producing an argument map, not just a pro/con list.

Output: Directed argument graphs with hierarchical decomposition and cross-branch dependency links. Usable in policy analysis, education, and critical thinking curricula.
argumentation critical thinking cross-branch reasoning
05 — Engineering & Infrastructure

Agents that understand systems

The hierarchical model mirrors how real systems are built — components within subsystems within systems. Agents at each level reason about their scope and report patterns upward.

Distributed Codebase Audit

Point the swarm at a large open-source codebase — the Linux kernel has about 30 million lines. Each agent gets a file or function and analyses it for bugs, security issues, style problems, and dead code. Then it messages agents responsible for related files to check cross-file dependencies.

"Your function calls mine with a null pointer that I never validate — one of us has a bug." A coordinator agent assigns subsystems and aggregates findings. Even if individual findings are modest, the coverage and cross-referencing is something no human team could replicate at this scale.

Output: Structured codebase audit with findings at every level — individual function, file, module, subsystem — with cross-reference links between related issues.
code review security audit cross-reference
Hierarchical Infrastructure Monitoring

A root agent monitors overall system health. It spawns children for each subsystem: message broker health, database health, scheduler performance, inference latency, deployment pipeline. Each spawns children for specific components — individual broker nodes, connection pool metrics, slow queries, replication lag.

The hierarchy adds causal reasoning. A leaf agent reports "this pod restarted 3 times, OOMKilled." Its parent checks node memory pressure. A sibling notices growing message queue lag. A coordinator synthesises: "the connection pool is leaking, causing pods to buffer messages in memory, triggering OOM kills, causing consumer lag — a feedback loop." That causal chain reasoning across signals is what dashboards can't do.

Output: Causal diagnostic trees, not just alerts. Navigable from high-level system health down to individual metric anomalies with full reasoning chains explaining how they connect.
monitoring causal reasoning DevOps observability
Adversarial Red Team / Blue Team

Half the agents defend a system — a simulated network, a set of policies, a logical argument. The other half attack. Attackers spawn sub-agents to probe different angles. Defenders spawn sub-agents to patch vulnerabilities. Both sides reason, adapt, and escalate.

The interesting output isn't who wins — it's the strategies that emerge. What attack patterns do the agents invent? What defensive formations do they converge on? The tree structure lets you trace the evolution of strategy through the parent-child reasoning chain.

Output: Emergent attack/defence strategy catalogues, vulnerability discovery timelines, escalation pattern analysis, security posture recommendations.
security adversarial strategy emergence
Simulating the Internet Ecosystem

Each agent is a website or online business. They compete for traffic, produce content, react to algorithm changes, copy successful competitors, form partnerships, and try to monetise. Introduce events: "the search engine changes its ranking algorithm to favour AI-generated content" or "strict new privacy laws take effect."

Watch how the ecosystem reshapes. Some agents thrive, some die, some pivot. The hierarchical structure groups sites by sector, business model, and region. Deeply meta: using an AI agent swarm to simulate how AI affects the web.

Output: Web ecosystem evolution maps, platform dependency analysis, content strategy emergence patterns, regulatory impact modelling.

06 — Creative & Generative

Hierarchical creativity

The fractal decomposition pattern maps naturally onto creative structures — symphonies decompose into movements, cities into neighbourhoods, novels into interlocking stories.

Fractal Musical Composition

Root agent: "compose a symphony." It decides on overall structure and spawns a child per movement. Movement agents decide internal structure and spawn section agents. Sections spawn phrase agents that write actual note sequences. Results flow back up — sections check that phrases cohere, movements check that sections flow, the root checks that movements form a satisfying whole.

Parents can reject and request revision: "your phrase is in the wrong key" or "this movement is too similar in mood to the previous." Every node stores its output — listen at any level of granularity. The revision history shows how the composition evolved through hierarchical negotiation.

Output: Complete compositions with full revision history, navigable at every structural level from individual phrases to complete works.
music generative hierarchical revision
Distributed Interconnected Fiction

A million agents, each writing a 200-word vignette about a character in a fictional city. Each agent knows about its three closest neighbours, and their stories must be consistent. If agent A writes that there was a fire on Main Street, agents B and C incorporate that into their narratives.

The agents negotiate plot points through messages. The output is a million interlocking stories forming a coherent tapestry of a fictional world, renderable as a navigable map — click any block and read that character's story, with links to neighbours.

Output: A navigable fictional world of a million interconnected micro-stories, explorable as a map with linked narratives.
fiction collaborative narrative emergent worldbuilding
Evolutionary Idea Generation

A root agent poses a problem. It spawns 10 children, each proposing a different solution. The root evaluates, picks the 3 best, and tells each winner to reproduce — spawning 3-4 children that are reasoned variations on the parent's approach. Mutations aren't random; they're considered: "what if I kept the core idea but applied it to a different market?"

After 20 generations, trace the lineage of the best solution back through its ancestors. The tree is literally an evolutionary tree, and every node stores its proposal independently. At scale, a massive solution space explored with reasoning, not randomness.

Output: Evolutionary trees of ideas with full lineage, fitness tracking per generation, strategy emergence analysis.
evolutionary ideation genetic algorithms innovation
07 — Practical Applications

Tools that deliver value today

Not every use case needs a million agents. The same hierarchical framework powers focused tools that decompose real business problems into specialist sub-agents.

Autonomous Website Generation

The framework's original application. Given a domain name and business brief, a hierarchy of agents researches the industry, plans site architecture, generates content for each section, selects design components, and deploys to production — all through hierarchical coordination.

Each page spawns its own content agents, which may spawn research sub-agents to investigate the industry before writing. The parent page agent synthesises content for consistency. The root site agent ensures cross-page coherence. Every agent stores its work independently — the research, the drafts, the revisions, the final output.

Output: Production-ready multi-page websites deployed to CDN, with a complete audit trail of every research finding, content decision, and design choice.
web development content generation deployment automation
Recursive Market Research

A top-level agent receives "analyse the UK restaurant industry." It decomposes: fast food, fine dining, casual, delivery-only. Each sub-sector agent decomposes further: burger chains, chicken, pizza, coffee. Leaf agents do actual research — web scraping, data gathering — and write focused micro-reports.

Results flow back up. The key advantage: every intermediate node stores its own synthesis. You don't just get a final report — you get a navigable tree of reports at every level. Read the executive summary or drill into "UK pizza delivery in the Midlands."

Output: Multi-level market research reports navigable from executive summary to granular sub-sector analysis, with the decomposition itself driven by agent reasoning, not pre-scripted.
market research adaptive decomposition drill-down reporting
Organisational Simulation

Model a company hierarchy — CEO spawns VP agents, VPs spawn directors, directors spawn team leads, team leads spawn individual contributors. The CEO sets "reduce costs by 15%." Each layer interprets, adapts, and passes targets down. Leaf agents reason about real impact: "my team lead wants fewer resources but my service needs to handle peak traffic."

Watch how information distorts flowing down (the telephone game of corporate communication) and how problems get filtered flowing back up (middle management hiding bad news). Run with different organisational structures and compare directive propagation effectiveness.

Output: Communication fidelity analysis, bottleneck identification, organisational structure effectiveness comparisons, information distortion heatmaps.
management communication org design
Disaster Response Coordination

An earthquake hits. The root agent is the national emergency coordinator, spawning regional commanders, local response teams, and individual units (search and rescue, medical, logistics, shelter). Information flows up from leaves — "building collapsed, estimated 30 trapped, need heavy equipment."

Each level makes autonomous decisions with its own stored state — a local commander doesn't wait for national approval to deploy available units. The hierarchy mirrors actual Incident Command System structures. Run with centralised vs decentralised decision-making and compare response effectiveness.

Output: Response effectiveness comparisons across command structures, complete after-action review trees, resource allocation optimisation analysis.
emergency response command structure ICS
Legal Case Analysis

A root agent receives a complex case with multiple legal questions. It spawns children for each issue: jurisdiction, evidence admissibility, statute interpretation, precedent application. Each issue agent spawns competing interpretation agents — prosecution's reading, defence's reading, plain meaning. Each builds its argument by spawning children that research specific precedents.

Results flow up: interpretations are weighed, legal issues are synthesised, and a reasoned analysis is produced. The stored tree shows exactly which precedents and arguments influenced each conclusion. Run for 1,000 cases and build a dataset for studying reasoning patterns.

Output: Structured legal analysis trees with full reasoning provenance, precedent mapping, competing interpretation comparison.
legal analysis competing interpretations precedent research
Peer Review Simulation

Give 1,000 root agents each a research paper. Each is a journal editor that spawns 3-5 reviewer agents with different expertise profiles and biases. Reviewers write independent reviews. The editor synthesises a decision. An author-agent responds, challenging criticisms and offering revisions. The editor mediates over multiple rounds.

Analyse outcomes: which reviewer types lead to better decisions? How often do hostile reviewers kill good papers? How often do generous reviewers let bad ones through? The hierarchy mirrors actual peer review structure, with every review and decision stored independently for audit.

Output: Peer review process analysis, reviewer bias impact studies, editorial decision quality metrics, science-of-science research datasets.

08 — Scaling

From 10 agents to 1,000,000

The architecture scales through progressive infrastructure changes, not application rewrites. Agent logic stays the same at every scale.

Scale Primary Constraint Architecture Infrastructure
10K agents Topic creation churn Current single-cluster architecture works 3–5 nodes, single Kafka cluster
100K agents K8s Job scheduling, Kafka topics Shared topic pools, multi-cluster dispatch 5–10 clusters, 8–10 Kafka brokers
1M agents Per-agent overhead, LLM throughput Worker pools, regional Kafka, distributed DB 50–100 clusters, GPU inference nodes, federated Kafka

Self-hosted inference

At scale, per-token API costs dominate. The framework is designed to run against self-hosted open-source LLMs (Mistral 7B, Llama 3 8B, Qwen 2.5) served via vLLM or llama.cpp on commodity hardware. A single GPU serving a 7B model with continuous batching handles 1,000–2,000 requests per minute — enough to sustain tens of thousands of concurrent agents.

For a million-agent run over 48 hours, the estimated infrastructure cost is $1,000–3,000 using a hybrid GPU inference cluster with CPU worker nodes — a fraction of what the same run would cost through API pricing.
