## What This Workflow Does

**Sequential Flow**:
1. Spawns 4 `content-creator` agents, each with a different role:
   - `hero_writer`
   - `features_writer`
   - `testimonials_writer`
   - `cta_writer`

2. Calls each agent in sequence to generate their section:
   - `generate_hero` → calls hero_writer
   - `generate_features` → calls features_writer
   - `generate_testimonials` → calls testimonials_writer
   - `generate_cta` → calls cta_writer

3. Aggregates all 4 responses into a single result

4. Completes and returns the full website

**Key Differences from Your Existing Workflow**:
- Your `simple-website-builder` has 2 agents (content-creator + html-developer) and includes S3 upload
- This `multi-section-website-builder` has 4 content-creator agents with different roles
- This focuses on content generation only (no HTML generation or S3 upload yet)
- Each section is a separate step with its own specialized prompt
