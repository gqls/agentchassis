## Proposed Website Builder Workflow

This workflow creates a simple website with multiple components:

## What This Workflow Demonstrates

**Flow progression**:
1. `spawn_header_writer` → spawns first content-creator with role "header_writer"
2. `spawn_about_writer` → spawns second content-creator with role "about_writer"
3. `spawn_contact_writer` → spawns third content-creator with role "contact_writer"
4. `generate_header` → calls header_writer agent to create header content
5. `generate_about` → calls about_writer agent to create about section
6. `generate_contact` → calls contact_writer agent to create contact section
7. `aggregate_content` → combines all three responses
8. `complete` → returns final aggregated result

**Key aspects**:
- **Sequential spawning**: Each agent spawn happens one after another
- **Sequential content generation**: Each section is generated in order
- **Data aggregation**: All responses are combined using `aggregate_data` action
- **Role-based routing**: Each `call_agent` uses `target_role` to find the right agent
- **Template variables**: The `{{business_name}}` and `{{business_type}}` are passed through from `input_data`
