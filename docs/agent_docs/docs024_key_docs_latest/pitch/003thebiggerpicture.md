The platform-mission framing is roughly: take a domain, understand its industry and audience, build a multipage site whose content and structure earn their place, learn from what works in the vertical, and avoid fabrication of facts the system shouldn't be inventing. The agent architecture serves that by carving the build into specialists with non-overlapping responsibilities — adoption gathers facts, planning decides structure, component-creator owns shapes, page-content-writer owns prose, queryresolve owns database-derived lists, and so on.

queryresolve exists specifically to draw a line between content the LLM is allowed to write (taglines, headlines, intro copy — things that need creative judgement) and content that has a database answer (the six tool pages on this site, in this order, with these titles and URLs). The architectural promise was: anything with source: query.* is reality, not invention.
