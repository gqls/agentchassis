# README — where we are (plain prose, append-only)

## 2026-08-15 — you asked for this lane; it exists, nothing is built yet

You ruled that each handler should be modular and responsible for its own thing, and agreed
with the recommendation that the modular unit is each finding-type's own classifier, run by
one shared engine instead of a family of near-identical cloned routers. This lane will build
that engine and move the three existing routers onto it (the required-fields one first, since
it is the hardened one; then the two image routers, which will pick up its hardening for free).
The first working session has a plan, a reading list and a checklist; its first real job is a
design round with the council on which of two shapes to build.
