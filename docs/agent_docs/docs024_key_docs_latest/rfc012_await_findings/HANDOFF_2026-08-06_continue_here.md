## The one finding in here that will save the next session real time

**A council seat's "approve, but" was a real defect, and the previous handoff had recorded it
as an open question nobody had looked at.** `reuse_agent` asked whether the detector's
routing-graph walk had been checked against `relaygaps.go` in the same package. It had not.

`relaygaps.go:207` walks through `validation.WalkSteps` deliberately, citing `bugs_open/144`:
*"a second hand-written descent goes blind in its own direction."* `sharedoutputs.go` had
written exactly such a descent, and its stated excuse — *"the walker does not expose
containment"* — **was false** (the qualified path's third-from-last segment IS the container).

And it had gone blind. A loop's body is declared under **either `substeps` or
`sub_workflow`**, and **`substeps` wins at execution** (`loop_actions.go:91`). The descent
read `sub_workflow` only, so it could not see the shape the runtime looks at first — and on
a step carrying both it walked the **inert** half, reporting a hazard in config that never
runs. Fixed in `867037f5a`; landmine filed with ten footprints.

**The transferable part is how it was proven, because the gap was invisible:** zero live
definitions carry `substeps` at any depth, so every live run was green and would have stayed
green. The proof had to be two tests that fail without the fix — plus an A/B showing the swap
is byte-identical over a 177-agent export, because 17 live agents *do* use `sub_workflow` and
their edges had to be shown not to move. **The recipe is in the RUNBOOK.**

## Landmines this lane found (all in `LANDMINES.md`, synced to `doc_notes`)

- **A hand-written walk into `sub_workflow` cannot see `substeps`** — and `substeps` is the
  half that RUNS, so on a step carrying both you audit the inert copy. Ten footprints.
- **A `strings <binary> | grep -c` counts distinct SPELLINGS, never SITES** — the linker
  dedupes identical literals, so a de-duplication refactor moves the number you were using to
  prove it shipped. Use a discriminating pair from the commit's own diff.
- **`LogActionEntry`'s merge fills a provenance you meant to set, and the suite stays green.**
- **A nil `Context` map marshals to `null`, not `{}`** — pin `"null"` in tests.
- **The RFC's own 13-key list is one short** — trust the live query, not the prose.
- **A green live run of the census proves the FLEET, never the DETECTOR** — the mutation test
  (sever the `config.then_step` edge, lose the finding) is what proves the detector.
- **Always run the concept-index uniqueness check, not just the row count.**
- **A census of a BEHAVIOUR must enumerate every way the behaviour is EXPRESSED** (NOTES
  misstep 10): the map-literal grep returns 24 awaiting actions; the true answer is 40,
  because adapter actions signal it through a typed result struct.
