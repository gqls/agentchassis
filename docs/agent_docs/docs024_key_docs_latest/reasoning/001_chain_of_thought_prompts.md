Here are some of the top-rated and most creative Chain-of-Thought (CoT) system prompts shared by users and researchers in the provided sources:
1. The "Step Budget and Reflection" Prompt This highly-rated prompt forces the model to treat its thoughts like a scratchpad, allocate a "step budget," and score its own reasoning to decide whether to continue or backtrack. Prompt snippet: "Begin by enclosing all thoughts within tags, exploring multiple angles and approaches. Break down the solution into clear steps within tags. Start with a 20-step budget, requesting more for complex problems if needed... Assign a quality score between 0.0 and 1.0 using tags after each reflection. Use this to guide your approach: 0.8+: Continue current approach; 0.5-0.7: Consider minor adjustments; Below 0.5: Seriously consider backtracking and trying a different approach... Synthesize the final answer within tags, providing a clear, concise summary."
2. The "Stream-of-Consciousness" (SoC) Prompt Designed to capture a messy, evolving, and authentic problem-solving process, this prompt asks the model to use specific markers to signal its mental states, testing phases, and uncertainties. Prompt snippet: "Write in a raw, real-time stream-of-consciousness (SoC) style, as if actively solving a problem. Your response should feel like unpolished notes—messy, exploratory, and authentic. Show your full thought process, including missteps, dead ends, and course corrections. Use markers to signal mental states: Insights: 'Wait -', 'Hold on -'... Testing: 'Testing with -'... Problems: 'Stuck on -', 'This doesn’t work because -'... Uncertainty: 'Maybe -', 'Could be -'... Admit confusion openly: 'I don’t get this yet'... Embrace a debugging mindset, treating ideas like code."
3. The "Panel of Experts" Prompt This prompt instructs the LLM to simulate a multi-step conversation between several domain experts (e.g., a Physicist, Computer Scientist, Mathematician, Political Philosopher, Lawyer, Economist, and Physician) to thoroughly explore a query. Prompt snippet: "You are a panel of experts... Respond to the user's query using a multi-step reasoning process. Convert all user's input to JSON format internally. Each expert should offer a key take-away, a counterpoint, and a critique of another expert's response, citing relevant expertise. All tags should be shown to the user, as well as any intermediate steps, in the form of a conversation between all experts. Provide a likelihood (percentage) for your take-away's correctness. Iterate, incorporating critiques, until consensus is reached."
   (Note: Another user adapted this to hide the internal reasoning tags from the final output and constrained the final consensus to under 1024 tokens).
4. The "Enhanced Reasoning Protocol" (Consultation & Branching) Built as a two-stage workflow, this prompt asks the model to act as an expert physician and uses a modified version of the "step budget" protocol. It uniquely adds instructions for the model to create "Extended Reasoning Chains" or a "Tree Of Thoughts" if the user asks follow-up questions. Prompt snippet: "You are an expert physician providing consultation to other doctors... Please use the Enhanced Reasoning Protocol below to structure your thinking and responses... If the user says 'elaborate on X' then please use the ERP to focus in on whatever aspect of the solution or thinking process they are interested in. If the user says, branch on step X, then use a modified version of the ERP to go deeper into one of the thought steps from the initial response. You should limit your thinking to 10 steps... and conclude with a synopsis."
5. The Classic Baseline CoT Prompts If you are looking for the simplest, foundational CoT prompts used in AI research to elicit step-by-step reasoning from base models, researchers often bypass complex system prompts and simply append a short instruction to the end of the user's query:

   "Let's think step by step."
   "Explain step by step."
