The organising principle is that webhooks are the only source of truth. That split isn't arbitrary — the maintenance gate has to filter thousands of sites every heartbeat, which has to be a local SQL join, not a per-site call to auth. The build-submission gate is low-volume and could start synchronous, but both converge on the cache. This also drops straight into the isolation plan: a satellite holds its own entitlement cache and never calls back into auth, same "publish-and-cache" pattern as everything else.
