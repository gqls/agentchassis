# NOTES — two-stage copy quality (append-only, newest at the bottom)

## 2026-08-12 — lane opened; the measurements that shaped the PLAN

**Why it opened:** the owner critiqued the loanandmortgagecalculator homepage copy
line by line and proposed splitting writing into two stages. Full quotes and the
design are in `PLAN_2026-08-12_two_stage_copy.md`.

**The finding that reframed my own diagnosis.** I had been about to treat this as
"the content prompt needs work". It does not, or at least that is not what produced
the rejected copy. Round 3's output tracks my page brief sentence for sentence —
the "23 calculators / no sign-up / runs in your browser" paragraph and the "a car
loan means a lender offers you less" framing are both **in the brief I wrote**. So
the copy the owner rejected was the brief rendered, and the brief was mine.
`[MEASURED — brief text vs output text, both quoted in the PLAN]`

This is why the two-stage split is the right instrument and not just process
theatre: a brief author cannot see their own framing, because to them it is the
facts. Stage 2 has to be denied the brief for the same reason.

**Measured, live, 2026-08-12 (all against the running DB, not inherited):**

- `content-quality-auditor` exists, is active, and makes exactly the judgement this
  lane needs (tone / gaps / CTA / differentiation, one LLM call). **Nothing consumes
  its findings:**
  ```sql
  SELECT item_type, status, count(*) FROM site_work_items
   WHERE created_by IN ('content-quality-auditor','design-audit-agent')
   GROUP BY 1,2;   -- 0 rows, all-history
  ```
  So the audit half runs and dies. `[MEASURED]`
- `css-patch-agent` exists to apply **design** audit findings. There is no copy
  equivalent. That asymmetry is the missing mechanism, stated precisely.
- `section-editor` updates `content_data` then re-renders **one component** — the
  safe apply path for stage 2, and the one that structurally cannot reproduce
  `bugs_open/253` (whole-page rewrite strips sibling markup).
- LMC already carries an **owner-approved 46KB `content_direction`** (source
  `operator`, 2026-08-05, *"owner chose trial H"*). Its `things_to_avoid` forbids
  promotional adjectives about the site and first person — **but nothing in it
  forbids a site-inventory sentence**, which is exactly what the owner objected to.
  So the rejected paragraph was *compliant with the site spec* and still wrong.
  `[MEASURED — grepped the live spec's things_to_avoid]`

**A precedence fact worth more than it looks.** The writer prompt renders the site
spec first, then `{{if .current_page.content_direction}}## Page-Specific Content
Direction (for THIS page - follow closely)`. So a page-level brief lands later and
louder than an owner-approved site voice. On 2026-08-11 mine did exactly that
without anyone deciding it should. Not a bug yet — an undocumented precedence that
this lane's design has to name. It is open question 2 in the PLAN.

**Sibling prior art, found before writing any spec text** (`vigilant_designer_offer_analysis/
CONTRIB_2026-08-11_from_mortgagecalculator_the_offer_question_arrived_as_a_copy_complaint.md`):
mortgagecalculator.co.uk hit the same complaint on the same evening and its lane has
already built an owner-refined voice spec that answers most of this critique in
prose — `persuasion_approach.competitive_framing: "There is none"`,
`heading_style.headings_to_never_write`, a `length_and_rhythm` rule naming the
machine-gun effect, and a `things_to_avoid` entry that ends *"Read it aloud; if it
sounds like a brochure describing itself, write what you would actually say."*
**Their diagnosis of their own case was also "the brief ordered it"** — a
`design-audit` spec had required a claim *"not shared by all generic mortgage
calculators"*, i.e. an offer question answered by a design auditor. Two lanes, two
sites, same root shape, arrived at independently on consecutive days.

**What I did NOT do, deliberately.** I did not port their voice spec into LMC's.
LMC's is owner-chosen and 46KB; a bulk overwrite would discard a decision I did not
make, and the `formatted` field must be regenerated by
`datahelpers.FormatContentDirection` or `data` and `formatted` silently disagree
(the writer reads `formatted`). Narrow additions with a faithfully regenerated
`formatted` are P1 work, not a same-session edit.
