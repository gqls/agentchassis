What webdesign.uk sells: a complete website for a small business, built and put live on the customer's own domain, for one fixed price paid once, with no ongoing fee and nothing the customer is locked into. Every number and named commitment on this page comes from the evidence base; where the evidence base holds no answer, the page says so plainly rather than inventing one. **contact** — a plain contact page: email and phone, what to put in a first message so the reply is useful, no response-time promises, no form. Later phases, recorded here for direction only and explicitly not to be built now: the short questionnaire that asks a visitor about their business and domain as an opening to a conversation, which arrives only once the chat service behind it exists; and a portfolio section, only once there is real accepted work to show.
