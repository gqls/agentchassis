# The live-sites tier needs a different instrument — measured, not asserted

New track opened 2026-09-03 by an owner ruling relayed via the sedo lane:
*"yes, list all live sites, we can price them quite high e.g. webdesign.uk can
be over 1 million because it's probably going to be worth that in a year or
so."* That reverses the do-not-sell fence for ~89 domains (50 framework/
Cloudflare + 39 Clook), which become listing candidates in a HIGH-VALUE tier
rather than keeps.

## The finding that governs this track

**Dynappraisal is not usable as the anchor above the tail, and there are now
two measurements showing it** `[MEASURED 2026-09-03]`:

| domain | Dynappraisal | the owner's own figure | ratio |
|---|---|---|---|
| relojistas.com | **$1,490** | **$12,000** (his Afternic floor, set by him, confirmed 2026-07-28) | **8×** |
| webdesign.uk | **$1,144** (my model, category median) | **">£1,000,000"** (his statement, 2026-09-03) | **~1,100×** |

relojistas is the stronger of the two because it is the only individual price
in the whole estate the owner set himself, and it is 8× the appraisal on a name
the appraiser had directly measured (not inherited).

**Why the instrument fails here, mechanically:** Dynappraisal prices a *domain
string* in its TLD's market. It cannot see (a) exact-match category leadership
— `webdesign.uk` is the generic term for an entire industry in a national TLD —
or (b) an attached business. Both are exactly what makes these 89 domains
different from the other 2,839.

**Why this does NOT undermine the bottom-500 work.** Liquidation-grade keyword
domains are Dynappraisal's home ground and the tail is where it should be
trusted. The two instruments are for two jobs: appraisal for the tail, something
else for the top. The error would be using one number for both.

## What the site data does and does not tell us

`[MEASURED 2026-09-03, from `pages`]` deployed page counts: webdesign.co.uk 151,
loanandmortgagecalculator.co.uk 62, finetuning.uk 57, leopardessconsulting.co.uk
52, gamesdesign.co.uk 48, ai-agent-orchestration.com 47, robot-hands.com 45,
loancalculator.co.uk 44, dartsonline.com 43, mortgagecalculator.co.uk 42,
idea.uk 36 … **webdesign.uk 14.**

That last figure is the point: **the owner's ~£1m is not about the site.**
webdesign.uk has the fewest deployed pages of any major property here. His
number is about the *name* plus the *business he expects it to carry* — so page
count is a weak input at this tier and must not be used as a proxy for value.

The estate's own strategy doc says the same thing from the other direction
(`docs/architecture/010-domain-value-maximisation.md`): naked domain $500–2,000
→ +site $1,000–3,000 → +traffic $5,000–20,000 → +revenue $10,000–100,000+.
Note the top of that published ladder is **$100,000+**, two orders below the
webdesign.uk figure — so a 7-figure price is outside the range this estate's own
thinking has used until today.

## What I can and cannot honestly produce

- **CAN:** a floor for every live site — the appraisal is a genuine lower bound,
  because it prices the name as if bare and these are not bare.
- **CAN:** relative ordering within the tier, and the site metrics that support
  a case (pages, deploy recency, whether it transacts).
- **CANNOT, today:** independently justify a 7-figure figure for any of them.
  There are **no realised sale prices anywhere in this estate** and no
  comparable-sales source is wired in. The honest status of "£1m" is **the
  owner's estimate**, recorded as his, not a measurement — and it should be
  labelled that way wherever it travels.
- **WOULD FIX IT:** real comparable sales for premium UK generics (DNJournal
  weekly charts, NameBio). Until then the owner's own knowledge is the best
  input available for this tier, and saying so is more useful than dressing a
  guess in a method.

## The tension worth stating once

A price set at what a name may be worth *in a year* is an **anchor**, not a
keen price — it is a decision not to sell yet, expressed as a number. That is a
legitimate strategy and it is the owner's call. Two consequences he should hold
deliberately rather than discover: (1) it will not sell at that price now, so
the listing is advertising rather than inventory; (2) a portfolio where the
premium names carry aspirational asks and the tail carries keen ones needs the
two kept visibly separate, or the tail's credibility carries the top's optimism.
