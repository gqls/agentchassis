# SUMMARY — programme opened (2026-08-02)

**What we're trying to do.** Give the estate two standing faculties it lacks: a vigilant senior
designer that continually refines every site from whole-site structure down to fine detail, and
an offer analyser that continually asks whether each site answers its target market's need in a
way that profits us — both built as checkers and handlers so improvement is the system's normal
behaviour, not a person's intervention.

**Where we've come from.** The owner raised the design half on 24 July; it was specified as
four features and never built. The platform's audits that did run produced correct findings that
nobody consumed — the brief-fidelity audit predicted the owner's own complaints three days early
and died unread. Sites converge on one brochure skeleton for measured, fixable reasons. The
offer half has its raw material (per-site monetisation analysis, audience definitions, a
42-proposition positioning register) written once at build time and never read back.

**What we've done.** Mapped the live system in three exploration passes, designed both
programmes in two planning passes, put the four genuinely-owner decisions to the owner and got
answers (manual triggers for now; designer first; trial Gemini vs Claude as the critic's eyes;
broad autonomy with two platform-constrained exceptions). The full plan is in
PLAN_2026-08-02 — organised around one rule learned from the failure above: every detector
ships with its drain, and each is proven by one real finding travelling to a changed page.

**Where we are now.** Plan approved; workstream docs opened; no code yet. The first phase is
plumbing: make findings flow (promotion runs on every audit path; the false "clean" report on
audited-out sites fixed; the browser render audit's measurements turned into routed work items).

**Where we're going.** Designer first: eyes (whole-site screenshots + a vision seam in the AI
service layer), then the screenshot critic with auto-applying fixers, then the recompose
handler that finally gives page-structure findings a consumer, then the anti-brochure
compose-time changes. Offer analyser second, on the same rails. The always-on schedule stays
off until the owner's separate go.
