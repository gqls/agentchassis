## 4. Durable rules banked this arc (beyond 016b v8)
- **kcat -P is line-delimited**: multi-line JSON body → one message per line; the chassis can marry your headers to a NEIGHBOURING message's body (`input_data: null` + someone else's workflow). Compact to single line; 086 script enforces.
- **Prompt seams lose intent**: a spec field can survive analysis and be ignored at generation if the generation prompt never renders it (analyze_tool rendered `spec.interactive_features`; recreate_tool didn't → Opus recreated the bugs). Fixed by 138's "Mandatory Behaviour Requirements" section. When adding a spec field, grep EVERY prompt_template that should render it.
- **Verify deploys by ancestry** (`git merge-base --is-ancestor <commit> <release>`): untracked files survive any number of release commits (the checker missed TWO releases before ad39ec6e).
- **`chunkContent`-class bugs**: content ≤ threshold returning early can hide a non-terminating path for weeks. Regression tests with timeouts catch loop regressions.
- **The anchor rule (Stage 5, settled)**: validate a criteria selector's leftmost id/class token only; confirm, never refute; `-EDIT` ids skipped; class tokens are whitespace-delimited (Go `\b` wrongly splits on hyphens).
- **"Completeness + validation passed" ≠ working** — twice demonstrated (June recreation introduced the bugs; run 2 recreated them). Tier 4 is the missing behavioural layer.
- **Snapshot before every agent_definitions change** (`snapshot_agent(type, reason)`); migrations via the runner; every migration carries its own guard DO block; workflow-altering migrations leave a `('pipeline','build')` note.
- Older essentials: env vars same-line prefix or exported; `agent_error_log` first read (orchestration_id is TEXT); `EXECUTING_STEP` forever = worker died (check pod restarts + Last State, capture crash logs IMMEDIATELY); prompt templates text→bare string / json→map with `.result`; aborted psql needs `ROLLBACK;`.
