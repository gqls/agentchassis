# SUMMARY — 2026-08-25. Phase C complete: every tool with external logic files is rebuilt.

*Written to be read aloud. Current state only; chronology in `README_where_we_are.md`, evidence in
`NOTES_native_rebuild_of_ported_tools.md`.*

## What we are trying to do

Replace all sixty-three hand-carried tools on webdesign.co.uk with tools the framework itself
generates at the same addresses, so every future platform improvement reaches them automatically.
All sixty-three go through the framework; the five rich applications go last, each reviewed by you.

## Where we have come from

Phase A (the small self-contained tools) finished on the twenty-first, though proving that claim
took a correction: our own tally had drifted by one, and four already-finished pages were briefly
un-retired by a housekeeping robot that edits retired content — both found, repaired, and the
un-retirement made impossible at the platform level with a reviewed fix that is now live and
proven. The count of old tools caught asserting something untrue about themselves reached
seventeen: a formula on the page that is not the formula in the code, a "dynamic" graph that never
changed, a share button that shared none of the state it promised.

## What we have done

Thirty-eight tools are now rebuilt and each one proven on the public site with caches defeated.
Phase C — the tools whose logic lived in separate script files, where the page alone cannot tell
you what the tool does — is complete: eleven rebuilt, and the twelfth turned out to be one of the
five rich applications, so it waits its turn in the finale. Along the way the class census itself
was corrected (a counting instrument had mistaken a code comment for a real script file), the
build recipe gained the cross-reference key whose absence had silently cost every hand-ordered
tool its mentions in related articles, and our first deliberately-keyless filing proved the
platform's new fallback picker works. Twelve orphaned script files are listed for one-batch
cleanup once the platform grows a retirement mechanism for them — filed, with the owner named.

## Where we are now

Thirty-eight of sixty-three. Nothing is blocked. The remaining twenty-five split cleanly:
twenty self-contained larger tools for the standard recipe, then the five rich applications —
mind-map, meme generator, logic architect, the micro-CMS and pasteboard — each a reimplementation
you have asked to see in person before the next begins.

## Where we are going

Phase B next, smallest first, the same six-step recipe that has now run thirty-eight times without
losing a page. Then the finale: one rich application at a time, each seen at the served page.
Done still means sixty-three of sixty-three, each proven at the served bytes.
