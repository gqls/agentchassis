# SUMMARY — 2026-08-25. Two thirds done, and the platform is paying the lane back.

*Written to be read aloud. Current state only; chronology in `README_where_we_are.md`, evidence in
`NOTES_native_rebuild_of_ported_tools.md`.*

## What we are trying to do

Replace all sixty-three hand-carried tools on webdesign.co.uk with tools the framework itself
generates at the same addresses, so every future platform improvement reaches them automatically —
your ruling, all sixty-three, no leave-alone option.

## Where we have come from

Phase A (the twenty-eight small self-contained tools) finished on the twenty-first, every one proven
at the real served pages. The recipe survived three platform walls, two double-tool incidents caused
by a wake-up channel that can deliver hours late, and a config defect that briefly broke every tool
build in the fleet — each one measured, repaired, and turned into a written rule.

## What we have done

**Forty-one of sixty-three tools are now rebuilt** — Phase A entire and most of Phase C, the
external-file tools — with the grind running in a sibling session at roughly five tools a day. The
old tools keep confirming the project's thesis: most were quietly broken, several lied about
themselves, and every rebuild removes a defect class rather than an instance.

The lane has also been paying the platform back, and the platform us. Our search-description fix and
our link-repair wiring (three writers, one found only by a new audit tool hours after the first two
were fixed) are both council-approved and live. The cross-mention machinery another lane built at
our request was proven by our real filings — and that exchange uncovered the sharpest fact of the
week: on this site, every topically-correct cross-mention parks behind the owned-page guard, because
the only writable pages are the shopfront. That finding is now recorded, triple-verified, in the
guard owner's register.

Today this session built the last deferred platform piece: the checker that finds the two
mechanically-decidable quality violations (inline click-handlers and pop-up dialogs) in every
not-yet-rebuilt tool across all twenty-four sites, filing one roadmap row per site instead of forty
noise items. The council's first review sent it back with a hard question — could the tombstone
filter hide live defects? — and answering it made the change better: the same filter turned out to
be missing from two sibling checks, which were spending LLM reviews on markup no visitor can reach.
All three are now filtered, tested, and back before the council.

One honest scar from today: I briefly recorded a page-count "drift" that was actually two sessions
using queries differing by one hyphen. Three lanes now carry the corrected rule — a claimed change
requires the same query run twice — and the false number never reached a fourth document.

## Where we are now

Forty-one rebuilt, twenty-two remaining: the tail of Phase C, then Phase B's larger tools, ending
with the five rich applications you review personally. Nothing is platform-blocked. Open on this
seat: one council verdict to read, and two post-roll demand checks for the new checker.

## Where we are going

The sibling grinds Phase C to its end, then Phase B. Your five rich-app reviews are the only
scheduled human step. The parked cross-mention question — whether owned pages should ever receive
a woven-in mention — sits with the guard's owner as a measured design decision, feeding the roadmap.
Done still means sixty-three of sixty-three, each proven at the served bytes.
