# Where we are — CTA target content pass

## 2026-08-15 — commissioned

You asked for this on 2026-08-15: the button-link repair left many pages on
the same site pointing their main button at the same tool (on three sites
it's the password checker, whatever the page is about). Works, but
repetitive. This piece of work varies each page's button to the most
appropriate tool for that page.

The shape: the writer rewords each button to name the right tool for the
page (it gets the site's real tool list to choose from), and the existing
link machinery then points the button at whatever the wording names. Two
proven parts, nothing new built. Worst-first order: finetuning.uk (39
buttons on one tool), the AI orchestration site (36), the gas wholesalers
site (28).

Nothing has run yet — this is the starting gun document. First act is a
one-site trial on finetuning.uk, checked before and after like everything
else this week.
