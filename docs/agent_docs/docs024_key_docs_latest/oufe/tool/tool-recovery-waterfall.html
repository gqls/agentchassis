Recovery waterfall and priming simulator

Value in a restructuring is distributed in order of priority: the most senior claim is paid in full before the next one receives anything. Set an enterprise value and a capital structure below, and the model shows where the value runs out — the point at which one class is partly paid and everything beneath it receives nothing.

The figures below are illustrative defaults, not any company's real capital structure. Change them to whatever you are working on. Everything is calculated in your browser: nothing you type is transmitted anywhere, and nothing is stored.

What this is. A deterministic arithmetic model of a strict priority waterfall, provided to explain a mechanism. It assumes one pool of value, one order of priority, and no structural subordination, intercompany claims, security packages, guarantees or contingent liabilities — all of which decide real cases and none of which are modelled here. It is educational scenario modelling. It is not investment advice, not a recommendation, not a valuation, and not a prediction about any company.
