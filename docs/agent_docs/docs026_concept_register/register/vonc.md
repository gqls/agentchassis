### VONC-012 — provocation gate, generator and scheduler (the unreviewed-publish chain)
- **status:** **CODE LIVE in chassis v1.0.1254 (2026-08-05 20:41Z, both replicas), council APPROVED round 1, and STILL nothing wired to publish** — added 2026-08-05, post-freeze

- **what:** The generative half VONC-011 was built to receive, completing VONC-002. Three actions, each of which can only fail in the direction of publishing LESS. `generate_provocations` writes LLM candidates into the pool as **drafts only** — the feed selects `status='approved' AND publish_on IS NOT NULL` and this action writes neither, so no path through it reaches the site. `gate_provocation` judges a draft in three layers: corpus-derived form rules and the fleet-wide banned-claim scan (both deterministic, run first, cannot fail open and cost no tokens), then a model judging safety, two-sidedness and factual problems. `schedule_provocations` assigns publish dates, one per calendar day, forward only.
- **why it is registerable:** it is the first mechanism in the estate that publishes model-written prose to a live site with **no human in the loop**, by explicit owner ruling (PLAN §10, 2026-07-31, recorded as taken — do not re-open). Any lane contemplating the same shape should read the gate's structure before inventing another.
- **the design that carries the whole thing — THE THESIS IS EXEMPT, THE PROSE IS NOT.** A provocation is a deliberately contestable assertion, so the claims rail would reject every good provocation in the corpus; but the supporting prose smuggles in ordinary factual claims that are fully subject to it (the four-day-week entry asserts the pilots "measure self-reported output"). A blanket "is this true?" rejects everything; a blanket "it is opinion" lets falsehoods through, which is `bugs_closed/043`. So `checkClaims` is given the body and teaser and **never the title**.
- **fail-closed is STRUCTURAL, not a guard anyone must remember:** `gateVerdict.Approved` is a bool whose zero value is rejection, and there is exactly one assignment of `true`, after every layer has spoken. No early return or error path can approve by omission. `TestGateRejectsWhenTheJudgeNeverRan` drives seven ways the judge yields no verdict — nil, error, timeout, empty reply, prose, a reply truncated mid-object, a renamed field — and requires a rejection from each, because §10.2 says that is the path never exercised by accident.
- **§10.5 lives in `nextPublishDates`**, which is pure and total so the rule is testable without a database: at most one date per day, always future, starting after the latest already in the pool. The ten-day hole behind 2026-08-05 is **deliberately not backfilled** — that is the catch-up the ruling forbids, and it would dump ten provocations into the archive at once while spending the buffer that makes one bad day survivable.
- **landmine — an artefact rollback is NOT a rollback here.** `publish_feed.sh --rollback` restores the previous `provocations.json`, and within six hours `provocation-feed-refresh` re-derives the feed from the pool and republishes the bad provocation. Any rollback for a scheduler that re-derives from source must act on the SOURCE. `builder/rollback_provocation.sh` retires the row instead, so the previous entry becomes today's through the same derivation the publisher uses and the two cannot disagree. Dry-run by default, and the preview **is** the real UPDATE inside a rolled-back transaction rather than a description of it.
