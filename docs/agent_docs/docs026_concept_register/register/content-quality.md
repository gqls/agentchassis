### CQ-029 — content_data recovery by template inversion, gated on a byte-identical round-trip
- **status:** built + APPLIED 2026-08-22 (`cmd/content-data-recover`, migration `540` writing 3 rows). Council `cd8e555d` submitted the same day. - **what:** recovers a page component's `content_data` from its OWN `rendered_html` by inverting the component template, and **refuses to emit anything whose re-render is not byte-identical to the stored HTML**.
