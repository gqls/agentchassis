"When a deployed page is rebuilt (e.g. a recreate rebuild queued as a site work item, or during re-adoption), the pipeline can report success and re-deploy the old content unchanged — because the page-content-writer's freshly generated sections never reach save_page_sections, so nothing new is persisted or rendered. The result is a silent no-op rebuild: the work item completes, git commits, timestamps advance, but the live page is stale — and because it presents as success, it's invisible without inspecting the actual stored components or rendered HTML. The example we are working on is the root index.html page on gamesdesign.co.uk."
